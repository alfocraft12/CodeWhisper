CodeWhisper es una biblioteca de código abierto diseñada para desarrolladores. Es un repositorio con prompts optimizados para herramientas de IA (ChatGPT, Claude, Gemini, GitHub Copilot, etc.) creados para acelerar la escritura de código, refactorización, creación de tests y resolución de bugs.

🚀 ¿Qué encontrarás aquí?
Prompts listos para usar: Desde arquitectura de software y desarrollo frontend/backend hasta automatizaciones y consultas SQL.

Resultados precisos: Prompts estructurados para evitar alucinaciones y obtener respuestas directas en tu entorno de desarrollo.

100% Gratuito y Accesible: Una colección pública para consultar y aplicar en tus proyectos diarios.

📌 Estado del Proyecto
Actualmente el proyecto está en etapa de curación y actualización de contenido por parte del equipo principal.
