## ✨ ¿Qué es SpellDev?

**SpellDev** es una biblioteca de código abierto diseñada para desarrolladores que quieren aprovechar al máximo las herramientas de Inteligencia Artificial.

El proyecto reúne una colección de **prompts cuidadosamente estructurados y optimizados** para trabajar con herramientas como:

- 🤖 ChatGPT
- 🧠 Claude
- ✨ Gemini
- 🐙 GitHub Copilot
- 🔧 Otras herramientas de IA para desarrollo

La idea es simple: **menos tiempo escribiendo prompts, más tiempo construyendo software.**

## 🎯 ¿Por qué SpellDev?

Trabajar con IA no consiste solamente en escribir:

> *"Hazme este código."*

Un buen prompt puede proporcionar **contexto, restricciones, objetivos y criterios de calidad**, permitiendo obtener resultados mucho más útiles y consistentes.

CodeWhisper busca convertir ese conocimiento en **prompts reutilizables, claros y fáciles de aplicar.**

---

## 🧠 Filosofía

SpellDev sigue tres principios:

### 🎯 Precisión
Prompts estructurados para reducir respuestas ambiguas y resultados innecesarios.

### 🛠️ Utilidad
Cada prompt está pensado para resolver problemas reales dentro de un entorno de desarrollo.

### ♻️ Reutilización
Los prompts pueden adaptarse y reutilizarse en diferentes proyectos, lenguajes y herramientas de IA.
