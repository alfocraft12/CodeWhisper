help ¿Cómo sugerir un prompt nuevo? expand_more
Puedes rellenar el formulario adjunto seleccionando la opción Sugerencia de Prompt o crear un Pull Request directamente en la carpeta /prompts de nuestro GitHub, adjuntando tests con métricas de tokens.
verified_user ¿El contenido es de dominio público? expand_more
Sí. Toda la biblioteca de SpellDev está liberada formalmente bajo la Licencia MIT. Esto garantiza uso comercial, modificación y redistribución libre tanto para startups como para investigadores independientes.
